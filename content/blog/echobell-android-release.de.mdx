# Echobell für Android ist jetzt verfügbar

Echobell ist jetzt auch für Android verfügbar. Sie können die Android-App bei [Google Play](https://play.google.com/store/apps/details?id=one.echobell.echobellandroid) herunterladen. Wenn Sie ein iPhone verwenden, bleibt Echobell weiterhin im [App Store](https://apps.apple.com/app/apple-store/id6743597198?pt=128151925&ct=blog-echobell-android-release-de&mt=8) verfügbar.

Dieses Release bringt den zentralen Echobell-Alert-Workflow auf mehr Geräte. Ob Serverausfälle, CI/CD-Fehler, wichtige E-Mails oder Trading-Signale: Sie können diese Ereignisse in dasselbe mobile Benachrichtigungssystem leiten.

## Was Android-Nutzer jetzt tun können

Die Android-App unterstützt den zentralen Echobell-Workflow:

- Kanäle mit Namen, Farben und Vorlagen für verschiedene Alert-Typen erstellen
- Webhook-URLs für Ereignisse aus Monitoring-Tools, CI/CD, Automatisierungen und Skripten verwenden
- E-Mail-Trigger nutzen, um wichtige Nachrichten in mobile Alerts umzuwandeln
- Direct verwenden, um persönliche Skripte oder abgeschlossene KI-Aufgaben direkt ans Telefon zu senden
- Abonnementlinks teilen, damit Teammitglieder denselben Alert-Stream erhalten

Wenn kritische Alerts bisher wegen fehlender Android-App in Chat-Tools, E-Mail oder einem anderen Push-Dienst gelandet sind, können Sie diese Ereignisse jetzt direkt mit Echobell verbinden.

## Warum das wichtig ist

Bei Alerting-Problemen geht es oft nicht darum, ob ein Tool eine Benachrichtigung senden kann. Entscheidend ist, ob die richtige Person sie rechtzeitig sieht. E-Mails gehen unter. Chat-Kanäle werden stummgeschaltet. Normale Pushs werden leicht übersehen.

Echobell basiert auf einer einfachen Idee: Wichtige Ereignisse sollten mit der passenden Dringlichkeit auf dem Telefon ankommen. Routine-Updates können leise bleiben, kritische Ereignisse können eskaliert werden, und geteilte Kanäle verhindern, dass Team-Alerts von manueller Weiterleitung abhängen.

Mit Android-Unterstützung brauchen Teams keine getrennten Alerting-Flows für verschiedene Telefonplattformen mehr. iOS- und Android-Nutzer können denselben Kanal abonnieren und dieselben kritischen Ereignisse auf ihren eigenen Geräten erhalten.

## Erste Schritte

1. Laden Sie Echobell bei [Google Play](https://play.google.com/store/apps/details?id=one.echobell.echobellandroid) oder im [App Store](https://apps.apple.com/app/apple-store/id6743597198?pt=128151925&ct=blog-echobell-android-release-de&mt=8) herunter
2. Erstellen Sie ein Konto und fügen Sie einen Kanal hinzu
3. Kopieren Sie die Webhook-URL oder E-Mail-Adresse des Kanals
4. Senden Sie ein Testereignis aus Monitoring, Automatisierung, CI/CD oder einem Skript
5. Passen Sie Vorlagen, Benachrichtigungstyp und Abonnenten an den echten Anwendungsfall an

Wenn Sie Echobell neu nutzen, beginnen Sie mit der [Schnellstartanleitung](/de/docs). Wenn Sie nur persönliche Skript- oder Aufgabenabschluss-Alerts benötigen, starten Sie mit [Echobell Direct](/de/docs/direct).

## Zuverlässigere Alerts weiter ausbauen

Das Android-Release ist ein neuer Ausgangspunkt. Wir werden die plattformübergreifende Erfahrung weiter verbessern, damit mehr kritische Workflows klar und rechtzeitig auf mobilen Geräten ankommen.

Wenn Ihr Team Echobell bereits nutzt, laden Sie Android-Nutzer ein, Ihre Kanäle zu abonnieren. Wenn Sie auf Android-Unterstützung gewartet haben, können Sie jetzt Ihren ersten Webhook verbinden.
