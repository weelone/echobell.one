# Echobell Android 版を公開しました

Echobell が Android でも利用できるようになりました。Android 版は [Google Play](https://play.google.com/store/apps/details?id=one.echobell.echobellandroid) からダウンロードできます。iPhone をお使いの場合は、引き続き [App Store](https://apps.apple.com/app/apple-store/id6743597198?pt=128151925&ct=blog-echobell-android-release-ja&mt=8) から利用できます。

今回のリリースにより、Echobell の主要なアラートワークフローがより多くのデバイスに広がります。サーバーダウン、CI/CD 失敗、重要メール、トレードシグナルなどを、同じモバイル中心の通知システムへ送れます。

## Android ユーザーができること

Android 版は Echobell の主要な使い方に対応しています。

- アラート種別ごとに名前、色、テンプレート付きのチャンネルを作成
- Webhook URL で監視ツール、CI/CD、自動化サービス、スクリプトからイベントを受信
- メールトリガーで重要なメールをモバイルアラートに変換
- Direct で個人スクリプトや AI タスク完了通知を直接スマートフォンへ送信
- チャンネル購読リンクを共有し、チームメンバーが同じアラートを受信

Android アプリがなかったために重要アラートをチャット、メール、別の push サービスへ送っていた場合でも、これからは Echobell に直接接続できます。

## なぜ重要なのか

多くのアラートの問題は、通知を送れるかどうかではありません。正しい人が時間内に気づけるかどうかです。メールは埋もれ、チャットはミュートされ、通常の push 通知は見逃されがちです。

Echobell は、重要なイベントを適切な緊急度でスマートフォンへ届けるために設計されています。日常的な更新は低ノイズに保ち、重要イベントは強い通知へ引き上げ、共有チャンネルで手動転送に依存しないチーム運用を作れます。

Android 対応により、チームはスマートフォンのプラットフォームごとに別々の通知フローを用意する必要がなくなります。iOS と Android のユーザーが同じチャンネルを購読し、自分のデバイスで同じ重要イベントを受け取れます。

## はじめ方

1. [Google Play](https://play.google.com/store/apps/details?id=one.echobell.echobellandroid) または [App Store](https://apps.apple.com/app/apple-store/id6743597198?pt=128151925&ct=blog-echobell-android-release-ja&mt=8) から Echobell をダウンロード
2. アカウントを作成し、チャンネルを追加
3. チャンネルの Webhook URL またはメールアドレスをコピー
4. 監視、自動化、CI/CD、スクリプトからテストイベントを送信
5. 実際の用途に合わせてテンプレート、通知タイプ、購読メンバーを調整

Echobell が初めての場合は [クイックスタートガイド](/ja/docs) から始めてください。個人のスクリプトやタスク完了通知だけが必要な場合は、[Echobell Direct](/ja/docs/direct) が最短です。

## より信頼できるアラートへ

Android 版の公開は新しい出発点です。今後もクロスプラットフォーム体験を改善し、より多くの重要なワークフローを明確かつ時間通りにモバイル端末へ届けられるようにしていきます。

すでにチームで Echobell を使っている場合は、Android ユーザーもチャンネルに招待できます。Android 対応を待っていた場合は、最初の Webhook を接続してみてください。
