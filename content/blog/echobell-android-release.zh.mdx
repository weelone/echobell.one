# Echobell Android 版已发布

Echobell 现在已经登陆 Android。你可以在 [Google Play](https://play.google.com/store/apps/details?id=one.echobell.echobellandroid) 下载 Android 版；如果你使用 iPhone，也可以继续从 [App Store](https://apps.apple.com/app/apple-store/id6743597198?pt=128151925&ct=blog-echobell-android-release-zh&mt=8) 下载 iOS 版。

这次发布让 Echobell 的核心提醒能力覆盖到更多设备：无论你在手机上接收服务器宕机告警、CI/CD 失败提醒、重要邮件，还是交易信号，都可以用同一个工作流把事件推到你的设备上。

## Android 用户现在可以做什么

Android 版延续了 Echobell 的核心用法：

- 创建频道，为每类告警设置名称、颜色和模板
- 使用 Webhook URL 接收来自监控系统、CI/CD、自动化工具和脚本的事件
- 使用邮件触发，把重要邮件转成手机提醒
- 使用 Direct，把个人脚本或 AI 任务完成事件直接推送到自己手机
- 与团队共享频道订阅链接，让相关成员接收同一类告警

如果你之前因为没有 Android 版本而只能把告警转到聊天工具、邮件或其它推送服务，现在可以把这些关键事件直接接入 Echobell。

## 为什么这很重要

很多告警系统的问题不是不能发通知，而是通知到不了真正需要处理的人。邮件容易被淹没，聊天工具容易被静音，普通推送也可能被忽略。

Echobell 的设计目标一直很明确：让重要事件以合适的紧急程度到达手机。普通更新可以保持低打扰，关键事件可以升级为更强提醒；团队频道则让值班、发布和业务告警不再依赖某个人手动转发。

Android 版发布后，团队不再需要按设备平台拆分提醒流程。iOS 和 Android 用户都可以订阅同一个频道，用各自的手机接收相同来源的关键事件。

## 快速开始

1. 在 [Google Play](https://play.google.com/store/apps/details?id=one.echobell.echobellandroid) 或 [App Store](https://apps.apple.com/app/apple-store/id6743597198?pt=128151925&ct=blog-echobell-android-release-zh&mt=8) 下载 Echobell
2. 创建账户并新建一个频道
3. 复制频道的 Webhook URL 或邮件地址
4. 从你的监控、自动化、CI/CD 或脚本里发送一条测试事件
5. 根据实际场景调整模板、通知类型和频道订阅成员

如果你还没有接入过 Echobell，可以从[快速入门文档](/zh/docs)开始；如果你只想给自己发送脚本或任务完成提醒，可以直接查看 [Echobell Direct](/zh/docs/direct)。

## 继续构建更可靠的提醒系统

Android 版只是一个新的开始。接下来我们会继续完善跨平台体验，让更多关键工作流可以稳定、清晰、及时地送达到手机。

如果你的团队已经在使用 Echobell，现在可以邀请 Android 用户一起订阅频道；如果你之前在等待 Android 版，现在就可以把第一个 Webhook 接进来。
