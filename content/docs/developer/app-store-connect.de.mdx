# App Store Connect Integration

App Store Connect bietet Webhook-Funktionalität, um Echtzeit-Benachrichtigungen über App-Status-Änderungen und TestFlight-Feedback direkt an Ihren Server zu senden. Durch die Integration von App Store Connect Webhooks mit Echobell können Sie sofortige Benachrichtigungen auf Ihrem mobilen Gerät erhalten, wann immer wichtige Ereignisse mit Ihren iOS-Apps auftreten.

<Callout type="info">
  App Store Connect Webhooks stehen Entwicklern mit den Rollen Account Holder,
  Admin oder App Manager zur Verfügung. Jeder Webhook kann nur für eine App
  gelten, und Sie können bis zu zehn Webhooks pro App erstellen.
</Callout>

## Voraussetzungen

- Ein Echobell-Konto mit mindestens einem erstellten Kanal
- Zugriff auf App Store Connect mit der Rolle Account Holder, Admin oder App Manager
- Eine aktive iOS-App in App Store Connect
- Ihre Echobell-Webhook-URL (verfügbar in Ihren Kanaleinstellungen)

## Was Sie überwachen können

1. **App-Versions-Status-Änderungen** — Einreichungs-Updates, Genehmigungen, Ablehnungen, Releases
2. **TestFlight-Ereignisse** — Build-Verarbeitung, Tester-Feedback, Einladungs-Status

## Schritt-für-Schritt-Anleitung

<Steps>
<Step>
### Echobell-Kanal erstellen

1. Öffnen Sie die Echobell-App
2. Erstellen Sie einen neuen Kanal (z.B. "App Store Connect")
3. Wählen Sie eine markante Farbe zur einfachen Identifikation
4. Fügen Sie Teammitglieder hinzu, die Benachrichtigungen erhalten sollen
</Step>
<Step>
### Benachrichtigungsvorlagen konfigurieren

Richten Sie Vorlagen ein, die Ihre App Store Connect-Ereignisse effektiv formatieren:

**Titel-Vorlage:**

```
[{{app.name}}] {{eventType}} - {{status}}
```

**Body-Vorlage:**

```
📱 App: {{app.name}}
🔄 Ereignis: {{eventType}}
📊 Status: {{status}}
⏰ Zeit: {{eventDate}}
💬 Nachricht: {{message}}
```

</Step>
<Step>
### Echobell-Webhook-URL abrufen

1. Navigieren Sie in Ihren Kanaleinstellungen zum Bereich **Triggers**
2. Kopieren Sie die bereitgestellte Webhook-URL
3. Halten Sie diese URL sicher
</Step>
<Step>
### App Store Connect Webhook konfigurieren

Gemäß [Apples offizieller Dokumentation](https://developer.apple.com/help/app-store-connect/manage-your-team/manage-webhooks/):

1. Melden Sie sich bei [App Store Connect](https://appstoreconnect.apple.com/) an
2. Navigieren Sie zu **Benutzer und Zugriff** → **Integrationen**
3. Unter **Zusätzlich** klicken Sie auf **Webhooks**
4. Klicken Sie auf die Schaltfläche (+) neben Webhooks
5. Konfigurieren Sie:
   - **Name**: "Echobell Benachrichtigungen"
   - **Payload-URL**: Ihre Echobell-Webhook-URL
   - **Secret**: Erstellen Sie eine sichere Zeichenfolge
   - **App**: Wählen Sie die zu überwachende App
   - **Ereignis-Trigger**: Wählen Sie gewünschte Ereignisse
6. Klicken Sie auf **Hinzufügen**
</Step>
<Step>
### Integration testen

1. In der Webhook-Liste klicken Sie auf Ihren neu erstellten Webhook
2. Klicken Sie oben rechts auf **Testen**
3. Sie sollten eine Test-Benachrichtigung in Echobell mit dem Ereignistyp "Ping" erhalten
</Step>
</Steps>

## Verfügbare Ereignis-Trigger

**App-Versions-Ereignisse:**

- **App Store Version State Changed**: Wenn sich der Review-Status ändert
- **App Store Version Released**: Wenn Ihre App veröffentlicht wird

**TestFlight-Ereignisse:**

- **TestFlight Beta Feedback**: Wenn Beta-Tester Feedback einreichen
- **TestFlight Beta Review State Changed**: Wenn sich der TestFlight-Status ändert

## Best Practices

1. **Kanalorganisation**: Erstellen Sie separate Kanäle für verschiedene Apps
2. **Team-Management**: Fügen Sie nur relevante Teammitglieder hinzu
3. **Benachrichtigungstypen**: Verwenden Sie Zeitkritisch für wichtige Ablehnungen

## Fehlerbehebung

Falls Sie keine Benachrichtigungen erhalten:

1. Überprüfen Sie, ob die Webhook-URL korrekt kopiert wurde
2. Prüfen Sie, ob der Kanal aktiv ist und Abonnenten hat
3. Verwenden Sie die Test-Schaltfläche in App Store Connect
