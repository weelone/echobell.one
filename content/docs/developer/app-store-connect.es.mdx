# Integración con App Store Connect

App Store Connect proporciona funcionalidad de webhook para enviar notificaciones en tiempo real sobre cambios de estado de aplicaciones y feedback de TestFlight. Al integrar los webhooks con Echobell, puedes recibir notificaciones instantáneas en tu dispositivo móvil cada vez que ocurran eventos importantes con tus aplicaciones iOS.

<Callout type="info">
  Los webhooks de App Store Connect están disponibles para desarrolladores con
  roles de Account Holder, Admin o App Manager. Cada webhook solo puede
  aplicarse a una aplicación, y puedes crear hasta diez webhooks por aplicación.
</Callout>

## Requisitos Previos

- Una cuenta de Echobell con al menos un canal creado
- Acceso a App Store Connect con rol de Account Holder, Admin o App Manager
- Una aplicación iOS activa en App Store Connect
- Tu URL de webhook de Echobell

## Qué Puedes Monitorear

1. **Cambios de Estado de Versión** — Envíos, aprobaciones, rechazos, lanzamientos
2. **Eventos de TestFlight** — Procesamiento de builds, feedback de testers, invitaciones

## Guía Paso a Paso

<Steps>
<Step>
### Crear un Canal de Echobell

1. Abre la aplicación Echobell
2. Crea un nuevo canal (ej. "App Store Connect")
3. Elige un color distintivo para facilitar la identificación
4. Agrega miembros del equipo que deberían recibir notificaciones
</Step>
<Step>

### Configurar Plantillas de Notificación

Configura plantillas que formateen efectivamente tus eventos:

**Plantilla de Título:**

```
[{{app.name}}] {{eventType}} - {{status}}
```

**Plantilla de Cuerpo:**

```
📱 App: {{app.name}}
🔄 Evento: {{eventType}}
📊 Estado: {{status}}
⏰ Hora: {{eventDate}}
💬 Mensaje: {{message}}
```

</Step>
<Step>
### Obtener tu URL de Webhook

1. En la configuración de tu canal, navega a la sección **Triggers**
2. Copia la URL de webhook proporcionada
3. Mantén esta URL segura
</Step>
<Step>

### Configurar Webhook de App Store Connect

Según la [documentación oficial de Apple](https://developer.apple.com/help/app-store-connect/manage-your-team/manage-webhooks/):

1. Inicia sesión en [App Store Connect](https://appstoreconnect.apple.com/)
2. Navega a **Usuarios y Acceso** → **Integraciones**
3. Bajo **Adicional**, haz clic en **Webhooks**
4. Haz clic en el botón agregar (+)
5. Configura:
   - **Nombre**: "Notificaciones Echobell"
   - **URL de Payload**: Tu URL de webhook de Echobell
   - **Secreto**: Crea una cadena secreta segura
   - **App**: Selecciona la aplicación a monitorear
   - **Triggers de Evento**: Selecciona los eventos deseados
6. Haz clic en **Agregar**
</Step>
<Step>

### Probar tu Integración

1. En la lista de webhooks, haz clic en tu webhook recién creado
2. Haz clic en **Probar** en la esquina superior derecha
3. Deberías recibir una notificación de prueba con tipo de evento "Ping"
</Step>
</Steps>

## Triggers de Evento Disponibles

**Eventos de Versión de App:**

- **App Store Version State Changed**: Cuando cambia el estado de revisión
- **App Store Version Released**: Cuando tu app es lanzada

**Eventos de TestFlight:**

- **TestFlight Beta Feedback**: Cuando los testers envían feedback
- **TestFlight Beta Review State Changed**: Cuando cambia el estado de TestFlight

## Mejores Prácticas

1. **Organización de canales**: Crea canales separados para diferentes apps
2. **Gestión de equipo**: Agrega solo miembros relevantes
3. **Tipos de notificación**: Usa Sensible al tiempo para rechazos importantes

## Solución de Problemas

Si no recibes notificaciones:

1. Verifica que la URL del webhook esté correctamente copiada
2. Comprueba si el canal está activo y tiene suscriptores
3. Usa el botón Probar en App Store Connect
